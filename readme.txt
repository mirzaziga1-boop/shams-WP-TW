SHAMS AL BOSNIA - WordPress Theme (1:1 Replica)
=================================================

INSTALLATION:
1. Zip this entire "shams-albosnia" folder into shams-albosnia.zip
2. Go to WordPress Admin > Appearance > Themes > Add New > Upload Theme
3. Upload shams-albosnia.zip
4. Click "Activate"

PAGE SETUP:
After activation, create these pages:

Pages > Add New:
- Title: "Home" | Slug: home | Template: (default)
- Title: "Cars" | Slug: cars | Template: "Cars Page"
- Title: "Accommodations" | Slug: accommodations | Template: "Apartments Page"
- Title: "About Us" | Slug: about-us | Template: "About Us Page"
- Title: "Bundles" | Slug: bundles | Template: "Bundles Page"
- Title: "Contact" | Slug: contact | Template: "Contact Page"

SET HOMEPAGE:
Settings > Reading > "A static page" > Front Page: "Home"

PERMALINKS:
Settings > Permalinks > Select "Post name" > Save

IMAGES:
All images are in assets/images/ folder.
Replace luxury-car.jpg with your own photo if desired.

FONTS:
Uses Google Fonts: Tajawal + Playfair Display (auto-loaded).

CSS:
Uses Tailwind CSS CDN + custom style.css with exact HSL color variables.

EDITING CONTENT:
All text is directly editable in the template files.
Open any .php file in a text editor and change the text.
